## Logo Usage

- **Full Logo:** `luxe-prize-draws-logo.svg` — use on dark backgrounds
- **Wordmark:** `luxe-prize-draws-wordmark.svg` — horizontal layouts
- **Seal:** `seal-badge.svg` — trust indicators, Ring-Fenced Guarantee
- Minimum size: **64×64 px**
- Always maintain clear space (minimum = 10% of logo width on all sides)
- Never distort, rotate, or recolour the logo
- Always use gold on black; never place on light backgrounds without an approved dark container

## Visual Language

- **Minimalist elegance** — generous spacing, no clutter
- **Gold on black** — high contrast, premium feel
- **Subtle glows** — soft filter on key icons
- **Serif headings, sans-serif body** — classic luxury pairing
- **Never use white backgrounds** — always dark containers for brand elements
